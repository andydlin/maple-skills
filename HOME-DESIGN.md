# A combined home with a clear hierarchy

## Primary: the Class Atlas

The main search and full class library answer the most common task: find a class or skill and open the inspector. Class-family filters and a 12-card initial grid keep the page manageable. The grid expands to all 59 classes; active search and family filters show all matching classes. Studio opens the first catalog class, Adele.

## Secondary: the personal workbench

A compact strip provides Continue Exploring, saved inspiration, and recent class visits. It supports returning users without turning the home into a dashboard. A fresh visitor sees one small getting-started prompt instead of three empty panels. All personal state stays in browser storage.

## Tertiary: discovery

Eight curated effect stills appear below the atlas, grouped by blade work, spellcraft, nature/spirit, and impact. Each card opens the exact skill, layer, and frame pictured. The page uses real R2 assets; there is no autoplay. After inspecting the source images, sparse particle frames were replaced with clearer Frozen Orb, Ravenous Spirit, and Wrath of Enlil stills.

## Interaction and verification

Home, Studio, class cards, saved skills, gallery links, and search results share URL-based routing with browser history. Direct studio links retain class/layer/frame selection. Returning Home stops playback and prevents hidden inspector state from rewriting the home URL.

Automated checks cover the 59-class atlas, family filters, expansion, class and all-skill search, home/studio navigation, saved activity, cold-start empty state, deep links, and continued player/export behavior. Curated metadata is checked against the source class catalogs, and all eight selected images were retrieved and visually inspected. Muted home text was darkened for readability.
